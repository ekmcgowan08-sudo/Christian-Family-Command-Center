# Prayer Weekly Planner Package

This package includes a branded printable PDF, a companion link hub, and the Christian Family Command Center workbook.

## Files
- Prayer_Weekly_Planner_Branded.pdf
- prayer-planner-link-hub.html
- christian_family_command_center.xlsx

## Use
1. Keep all files in the same folder after download.
2. Open the PDF and use the companion access page or open the HTML link hub.
3. If your PDF viewer blocks file links, open the link hub in a browser and click the workbook there.
4. Print the planner pages or annotate digitally.
