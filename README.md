# Christian-Family-Command-Center
Intended as a central workspace for Christian products, social content, KPIs, assets, links, and business operations.

## Layout

- `products/` — recovered, sellable product files (workbook, prayer planner, HQ
  dashboard, Spare Chair video kit, Christian Ministry Assets Gumroad catalog).
  `weekly-family-reset-checklist/` is the one exception: newly created, not
  recovered — see the audit log entry for why.
- `assets/pinterest-pins/` — the 5 canonical Pinterest pin designs.
- `marketing/storefront/` — the storefront cover image.
- `social-command-center/` — the standalone front-end concept demo.
- `docs/planning/` — full-length planning/copy docs (handover notes, welcome
  email sequence, execution plan, prayer planner product copy).
- `docs/audit-log.md` — the running, dated record of what's been recovered,
  verified, and what's still outstanding. Read this first.
- `webapp/` — the actual Christian Family Command Center web app: a
  password-protected dashboard each family logs into, with its own login
  per member, a shared family calendar, optional per-member Google
  Calendar/Gmail connections, and a phone-calendar (iOS/Android) sync
  feed. See `webapp/README.md` to run or deploy it.
